# Первый запуск

VI — браузер, у которого нет вкладок. Страница здесь занимает целое окно, окна
стоят в ряд и прокручиваются вбок, а рядов столько, сколько у вас дел. Всё
остальное — обычный браузер: адрес, история, закладки, загрузки, расширения.

Раскладка взята у [niri](https://github.com/YaLTeR/niri), оконного менеджера
для Linux. Три слова, которыми она описывается, стоит запомнить сразу:

| | |
|---|---|
| **окно** | одна страница. Не вкладка: у окна нет заголовка, оно и есть страница от края до края |
| **лента** | ряд окон, уходящий вправо. Прокручивается бесконечно |
| **рабочий стол** | одна лента целиком. Столы стоят стопкой, на экране всегда ровно один |

Ленту двигают вбок, между столами переключаются вверх-вниз. Это вся навигация.

## Что на экране

Сверху — одна строка на всё приложение, и она про то окно, которое вы читаете:
адрес, замок, щит блокировки, звёздочка закладки, стрелки назад и вперёд. У
каждого отдельного окна своего заголовка нет — двенадцать окон в ленте не хотят
двенадцати адресных строк.

Слева в той же строке — кнопка профиля с его именем и цветом и кнопка
раскладки. Справа — переключатель рабочих столов, обзор и кольцо загрузок,
которое появляется, только когда что-то скачали.

Крестик, закрывающий окно, — единственное, что осталось на самом окне: он в его
правом верхнем углу и невидим, пока туда не наведёшь курсор.

## Новое окно

`⌘T` — новое окно справа от текущего. Оно открывается не на чьей-то домашней
странице, а на **стартовой странице** VI: одно поле, в которое одинаково
годятся и запрос, и адрес.

Пока вы печатаете, под полем собираются подсказки, в таком порядке:

1. строка с адресом — если введённое похоже на адрес (`apple.com`,
   `localhost:3000`, что угодно со схемой), чтобы `↩` открыл его, а не искал;
2. до четырёх страниц **из истории этого профиля** — по заголовку и хосту,
   часто посещённые выше;
3. подсказки поисковика, каждая подписана «Поиск DuckDuckGo» или «Поиск
   Google», чтобы было видно, куда уйдёт `↩`.

`↑` `↓` ходят по строкам, `↩` открывает выбранную, `Esc` очищает поле.

Поисковик переключается фишкой слева от поля или в меню **Навигация ▸
Поисковик**; по умолчанию DuckDuckGo. Выбор общий для стартовой страницы,
адресной строки и ассистента.

::: tip Запрос уходит с машины по мере набора
Так работает любая служба подсказок. VI отправляет их отдельной сессией — без
кук, без кэша, ничего не привязано к профилю. Кроме этого стартовая страница в
сеть не ходит вообще.
:::

## Первые десять минут

Порядок, в котором стоит попробовать:

1. `⌘T` три-четыре раза, открыть в каждом окне что-нибудь. Получилась лента.
2. `⌥←` и `⌥→` — пройтись по ней. `⌥` здесь заменяет niri-шный `Mod`.
3. `⌥↓` — перейти на рабочий стол ниже. Он пустой; откройте там своё.
4. `⌥O` — обзор: всё разом, столы стопкой. Клик по окну открывает его,
   перетаскивание переносит, двойной клик по имени стола переименовывает его.
5. `⌥W` — окно во всё окно, без зазоров. Ещё раз — обратно.
6. Навести курсор в зазор рядом с активным окном. Лента наклонится и покажет,
   что там: `‹` или `›`, если окно, и контур, если окна ещё нет, — клик в этом
   месте создаст его.

Клавиатура ни для чего из этого не обязательна: [у каждой операции есть
мышиный эквивалент](/layout#мышью-и-без-клавиатуры).

## Где что лежит

Всё — на вашей машине, в `~/Library/Application Support/org.deffun.six`:

| | |
|---|---|
| `state.json` | окна, ленты, рабочие столы, чаты агентов — снимок сессии |
| `six.sqlite` | история, закладки, разрешения сайтов, настройки |
| `Profiles/<имя>/` | закладки профиля отдельными файлами и папка черновиков для агентов |
| `Blocking/`, `Models/`, `Thumbnails/`, `Screenshots/` | списки фильтров, модель для поиска по смыслу, картинки окон, снимки |

Сессия переживает перезапуск целиком: окна встают там же, где стояли, с теми же
адресами и позицией прокрутки, а чаты с агентами продолжаются.

## Сделать браузером по умолчанию

Меню **six ▸ Сделать six браузером по умолчанию…**, или System Settings ›
Desktop & Dock › Default web browser. После этого ссылки из других приложений и
`.html`-файлы из Finder открываются новыми окнами в ленте.
