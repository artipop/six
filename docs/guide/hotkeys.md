# Горячие клавиши

На странице `Enter` отправляет форму или активирует кнопку, а `Пробел` и `Shift+Пробел`
прокручивают её вниз и вверх. В текстовом поле они служат для ввода. Если страница
не использует клавишу и прокручивать нечего, системного звука ошибки нет — как и для `Esc`,
стрелок, `Home` и `End`.

## Вкладки

| | |
|---|---|
| `⌘T` | новая вкладка — в самом конце, вне групп |
| `⌘W` | закрыть вкладку |
| `⌘⇧T` | вернуть последнюю закрытую вкладку на её место |
| `⌘⇧]` `⌘⇧[` | следующая / предыдущая вкладка |
| `⌘1` … `⌘8` | вкладка по номеру, `⌘9` — последняя |
| `⌘`-клик `⇧`-клик по вкладке | выбрать вкладки по одной / подряд; меню любой из них относится ко всем |

## Перелёт между вкладками

| | |
|---|---|
| `⌃Tab` | держите `⌃`: все вкладки профиля, из всех групп, картинками, в том порядке, в котором вы в них заглядывали, и та, куда вы попадёте, — посередине. Каждое нажатие — шаг по кольцу, `⌃` отпущен — перелёт |
| `⌃⇧Tab` | то же кольцо, но только по текущей группе; в уже открытом кольце — шаг назад |
| `⌃⇧←` `⌃⇧→` | соседняя карточка, слева или справа. `⇧` здесь не украшение: чистые `⌃←` / `⌃→` забирает сам macOS (Mission Control, «перейти на пространство»), до браузера они не доходят |
| `↩` | лететь сейчас, не дожидаясь, пока отпустите `⌃` |
| `Esc` | отпустить кольцо и никуда не лететь |

Одно нажатие `⌃Tab` — переключатель между двумя последними вкладками. Других
профилей в кольце нет, и оно помнит только этот запуск.

## Браузер

| | |
|---|---|
| `⌘R` | перезагрузить страницу (то же делает ⟳ рядом с адресом) |
| `⌘⇧R` | перезагрузить с сервера — мимо кэша, всё запрашивается заново |
| `⌘.` | остановить загрузку |
| `⌘[` `⌘]` | назад / вперёд по истории вкладки (то же делают ‹ ›) |
| `⌘,` | настройки — `savoia://configuration`, вкладкой, как любой другой адрес |
| `⌘⇧N` | новый документ |
| `⌘⇧P` | новое приватное окно |
| `⌘⇧C` | скопировать адрес вкладки целиком; в поле появится галочка (то же — «Правка» ▸ «Скопировать адрес»). На стартовой странице, в документе и в приложении копировать нечего — там клавиша ничего не делает |
| `⌘F` | найти на странице; `↩` / `⇧↩` — к следующему / предыдущему совпадению, `Esc` — закрыть |
| `⌘L` | каретка в адресную строку |
| `⌘E` | строка ассистента: показать или убрать |
| `⌘⇧E` | чаты с агентами — вкладкой |
| `⌘Y` | история профиля |
| `⌘D` | закладка на страницу (ещё раз — удалить) |
| `⌘⌥B` | закладки и поиск по ним |
| `⌘S` / `⌘⇧S` | сохранить / сохранить как… |
| `⌘⇧L` | перевести страницу |
| `⌥⇧T` | перевести выделенное |
| `⌥⇧H` | выделить выбранное на странице |
| `⌥⇧P` | видео в плавающее окошко «картинка в картинке» и обратно |
| `⌥⌘A` | [слой доступности](/accessibility) над страницей — включить и выключить |
| `⌥⌘I` | [веб-инспектор](/devtools) на этой вкладке — открыть и закрыть |
| `⌘` + клик по ссылке | открыть в новой вкладке, в фоне |

`⌥⇧T`, `⌥⇧H` и `⌥⇧P` сначала получает страница: если сайт занял это сочетание сам,
оно остаётся сайту. В текстовом поле они печатают свои символы.

## Стартовая страница

| | |
|---|---|
| набор текста | подсказки: адрес, страницы из истории, подсказки поисковика |
| `↑` `↓` | по строкам |
| `↩` | открыть выбранное или введённое |
| `Esc` | очистить поле; в пустом поле — убрать из него каретку. Клик мимо поля делает то же самое |

## Закладки `⌘⌥B`

| | |
|---|---|
| набор текста | поиск по смыслу; под каждой строкой — совпавший кусок |
| `↑` `↓` `↩` | по строкам, открыть новой вкладкой |
| `⌘⌫` | удалить закладку вместе с файлом |
| `Esc` | закрыть |

## История `⌘Y`

| | |
|---|---|
| набор текста | фильтр по заголовку и адресу |
| `↩` | открыть новой вкладкой |
| `⌘⌫` | забыть запись |
| `Esc` | закрыть |

## Строка ⌘E

| | |
|---|---|
| `↩` | спросить; в пустой строке — применить полученный ответ |
| `←` `→` | у поля и у выделения — выбрать действие |
| `/` | действия списком; с агентом — ещё и прежние разговоры |
| `↑` `↓` | после `/` — ходить по найденным разговорам |
| `⇥` | после `/` — поставить найденное действие в строку значком |
| `⌘⌫` | в пустой строке — убрать значок действия или разговора |
| `Esc` | убрать строку |

## Вкладка чата

| | |
|---|---|
| `↩` | отправить |
| `⌘↩` | отправить, даже когда поле многострочное |
