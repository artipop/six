# Горячие клавиши

`⌥` — лента, `⌘` — браузер. У `⌥` на Mac уже есть свои дела — шаг по словам,
набор «∑» и «ø», прокрутка страницы, сочетания самих сайтов, — поэтому сначала
клавишу получает то, что у вас в фокусе, и лента отвечает, только если клавиша
никому не понадобилась. Для случаев, когда нужно наверняка, есть `⌃⌥`: эти клавиши
лента забирает всегда. Ничего из этого не обязательно:
[у каждой операции есть мышиный эквивалент](/layout#мышью-и-без-клавиатуры).

## Лента

| | |
|---|---|
| `⌥←` `⌥→` | фокус на окно левее / правее |
| `⌥⇧←` `⌥⇧→` | сдвинуть окно влево / вправо |
| `⌥Home` `⌥End` | первое / последнее окно ленты (то же — правый клик по фону) |
| `⌥↑` `⌥↓` | рабочий стол выше / ниже |
| `⌥⇧↑` `⌥⇧↓` | перенести окно на стол выше / ниже и уйти с ним; разделённая колонка едет парой |
| `⌥W` | во всю ширину |
| `⌥S` | разделить: соседнее окно встаёт рядом в ту же колонку; ещё раз — обратно на ленту |
| `⌥O` | обзор (`Esc` — выйти) |
| `⌥C` | центрировать активное окно (по умолчанию включено) |
| `⌥` + прокрутка вверх-вниз | рабочий стол за жест |
| `⌥` + прокрутка вбок | окно за каждые ~55 точек движения — сколько пройдёте, столько и окон |

**Сначала страница, потом лента.** Пока каретка стоит в поле с текстом — в адресной
строке, в строке `⌘E`, в поле на самой странице — стрелки с `⌥` двигают каретку, а
`⌥W`, `⌥S`, `⌥O`, `⌥C` печатают свои символы. На странице, которую можно прокрутить,
`⌥↑` и `⌥↓` листают её на экран — до самого конца, не перескакивая на соседний стол.
Если сайт сам занял `⌥`-сочетание (Google Таблицы переключают им листы), оно
остаётся сайту. На пустом поле, с которого начинается новое окно, и на странице без
прокрутки клавиши ходят по ленте.

| | |
|---|---|
| `⌃⌥←` `⌃⌥→` | фокус на окно левее / правее — из поля, из игры, откуда угодно |
| `⌃⌥⇧←` `⌃⌥⇧→` | сдвинуть окно влево / вправо |
| `⌃⌥↑` `⌃⌥↓` | рабочий стол выше / ниже |
| `⌃⌥⇧↑` `⌃⌥⇧↓` | перенести окно на стол выше / ниже |
| `⌃⌥O` | обзор |

У `⌃⌥` на Mac нет ни текстового, ни системного значения, поэтому эти клавиши
лента берёт первой, не отнимая ни у кого ничего.

Там, где лента кончилась, жест не пропадает молча: край, в который вы упёрлись,
подсвечивается цветом профиля, резинка становится туже, и ничего не едет —
потому что в ту сторону ничего нет.

## Перелёт между окнами

| | |
|---|---|
| `⌃Tab` | держите `⌃`: все окна профиля, со всех рабочих столов, картинками, в том порядке, в котором вы в них заглядывали, и то, куда вы попадёте, — посередине. Каждое нажатие — шаг по кольцу, `⌃` отпущен — перелёт |
| `⌃⇧Tab` | то же кольцо, но только по текущей ленте; в уже открытом кольце — шаг назад |
| `⌃⇧←` `⌃⇧→` | соседняя карточка ряда, слева или справа. `⇧` здесь не украшение: чистые `⌃←` / `⌃→` забирает сам macOS (Mission Control, «перейти на пространство»), до браузера они не доходят |
| `↩` | лететь сейчас, не дожидаясь, пока отпустите `⌃` |
| `Esc` | отпустить кольцо и никуда не лететь |

`⌥←` `⌥→` ходят по ленте — там, где окна **стоят**; `⌃Tab` ходит по памяти —
в том порядке, в котором окна **смотрели**. Поэтому одно нажатие `⌃Tab` — это
переключатель между двумя последними окнами. `⌃Tab` — по всем столам, `⌃⇧Tab` —
только по текущей ленте; других профилей нет ни там, ни там, и только за этот запуск.

## Браузер

| | |
|---|---|
| `⌘R` | перезагрузить страницу (то же делает ⟳ рядом с адресом) |
| `⌘⇧R` | перезагрузить с сервера — мимо кэша, всё запрашивается заново |
| `⌘.` | остановить загрузку |
| `⌘[` `⌘]` | назад / вперёд по истории самого окна (то же делают ‹ ›) |
| `⌘,` | настройки — `six://configuration`, колонкой в ленте, как любой другой адрес |
| `⌘T` | новое окно в ленте, справа от активного |
| `⌘W` | закрыть активное окно |
| `⌘⇧T` | вернуть последнее закрытое окно на его место |
| `⌘⇧N` | новый документ |
| `⌘⇧P` | новое приватное окно |
| `⌘⇧C` | скопировать адрес активного окна целиком; в поле появится галочка (то же — «Правка» ▸ «Скопировать адрес»). На стартовой странице, в документе и в окне приложения копировать нечего — там клавиша ничего не делает |
| `⌘F` | найти на странице; `↩` / `⇧↩` — к следующему / предыдущему совпадению, `Esc` — закрыть |
| `⌘L` | каретка в адресную строку |
| `⌘E` | строка ассистента: показать или убрать |
| `⌘⇧E` | чаты с агентами — колонкой в ленте |
| `⌘Y` | история профиля |
| `⌘D` | закладка на активную страницу (ещё раз — удалить) |
| `⌘⌥B` | закладки и поиск по ним |
| `⌘S` / `⌘⇧S` | сохранить / сохранить как… |
| `⌘⇧L` | перевести страницу |
| `⌥⇧T` | перевести выделенное |
| `⌥⇧H` | выделить выбранное на странице |
| `⌥⇧P` | видео в плавающее окошко «картинка в картинке» и обратно |
| `⌘` + клик по ссылке | открыть в новом окне справа, в фоне |
| `Esc` | закрыть обзор; иначе клавиша страницы |
| `↩` | в обзоре — перейти в окно в фокусе |

## Стартовая страница

| | |
|---|---|
| набор текста | подсказки: адрес, страницы из истории, подсказки поисковика |
| `↑` `↓` | по строкам |
| `↩` | открыть выбранное или введённое |
| `Esc` | очистить поле; в пустом поле — убрать из него каретку, чтобы `⌥`-клавиши снова ходили по ленте. Клик мимо поля делает то же самое |

## Закладки `⌘⌥B`

| | |
|---|---|
| набор текста | поиск по смыслу; под каждой строкой — совпавший кусок |
| `↑` `↓` `↩` | по строкам, открыть новым окном |
| `⌘⌫` | удалить закладку вместе с файлом |
| `Esc` | закрыть |

## История `⌘Y`

| | |
|---|---|
| набор текста | фильтр по заголовку и адресу |
| `↩` | открыть новым окном |
| `⌘⌫` | забыть запись |
| `Esc` | закрыть |

## Строка ⌘E

| | |
|---|---|
| `↩` | спросить; в пустой строке — применить полученный ответ |
| `←` `→` | у поля и у выделения — выбрать действие |
| `/` | действия списком; с агентом — ещё и прежние разговоры |
| `↑` `↓` | после `/` — ходить по найденным разговорам |
| `⇥` | после `/` — поставить найденное действие в строку значком |
| `⌘⌫` | в пустой строке — убрать значок действия или разговора |
| `Esc` | убрать строку |

## Окно чата

| | |
|---|---|
| `↩` | отправить |
| `⌘↩` | отправить, даже когда поле многострочное |

## Обзор

| | |
|---|---|
| `↩` | подтвердить имя рабочего стола, пока его переименовывают |

::: tip Если `⌥`-клавиша «не сработала»
Скорее всего, она понадобилась тому, что в фокусе: каретка в поле сдвинулась на
слово, страница пролистнулась, сайт выполнил своё сочетание. Так и задумано —
`⌥` на Mac в первую очередь про текст. `⌃⌥←` `⌃⌥→` `⌃⌥↑` `⌃⌥↓` работают всегда.
:::
