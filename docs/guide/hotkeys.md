# Горячие клавиши

`⌥` — лента, `⌘` — браузер. Меню для `⌥`-клавиш нет: они читаются раньше
страницы и потому работают всегда. Ничего из этого не обязательно:
[у каждой операции есть мышиный эквивалент](/layout#мышью-и-без-клавиатуры).

## Лента

| | |
|---|---|
| `⌥←` `⌥→` | фокус на окно левее / правее |
| `⌥⇧←` `⌥⇧→` | сдвинуть окно влево / вправо |
| `⌥Home` `⌥End` | первое / последнее окно ленты |
| `⌥↑` `⌥↓` | рабочий стол выше / ниже |
| `⌥⇧↑` `⌥⇧↓` | перенести окно на стол выше / ниже и уйти с ним |
| `⌥W` | во всю ширину |
| `⌥O` | обзор (`Esc` — выйти) |
| `⌥C` | центрировать активное окно (по умолчанию включено) |
| `⌥` + прокрутка вверх-вниз | рабочий стол за жест |
| `⌥` + прокрутка вбок | окно за жест |

Пока каретка стоит в поле ввода — в адресной строке, в строке `⌘K`, на стартовой
странице — `⌥←` и `⌥→` остаются перемещением по словам, как и были. Но только
пока в поле есть что перешагнуть: на пустом поле, с которого начинается новое
окно, те же клавиши ходят по ленте.

Там, где лента кончилась, жест не пропадает молча: край, в который вы упёрлись,
подсвечивается цветом профиля, резинка становится туже, и ничего не едет —
потому что в ту сторону ничего нет.

## Перелёт между окнами

| | |
|---|---|
| `⌃Tab` | держите `⌃`: окна текущей ленты картинками, в том порядке, в котором вы в них заглядывали, и то, куда вы попадёте, — посередине. Каждое нажатие — шаг по кольцу, `⌃` отпущен — перелёт |
| `⌃⇧Tab` | то же, в обратную сторону |
| `⌃←` `⌃→` | тот же шаг, сказанный так, как карточки лежат |
| `↩` | лететь сейчас, не дожидаясь, пока отпустите `⌃` |
| `Esc` | отпустить кольцо и никуда не лететь |

`⌥←` `⌥→` ходят по ленте — там, где окна **стоят**; `⌃Tab` ходит по памяти —
в том порядке, в котором окна **смотрели**. Поэтому одно нажатие `⌃Tab` — это
переключатель между двумя последними окнами. Только окна текущей ленты — не
других столов и не других профилей, — и только за этот запуск.

## Браузер

| | |
|---|---|
| `⌘R` | перезагрузить страницу (то же делает ⟳ рядом с адресом) |
| `⌘⇧R` | перезагрузить с сервера — мимо кэша, всё запрашивается заново |
| `⌘.` | остановить загрузку |
| `⌘[` `⌘]` | назад / вперёд по истории самого окна (то же делают ‹ ›) |
| `⌘,` | настройки — `six://settings`, колонкой в ленте, как любой другой адрес |
| `⌘T` | новое окно в ленте, справа от активного |
| `⌘W` | закрыть активное окно |
| `⌘⇧T` | вернуть последнее закрытое окно на его место |
| `⌘⇧N` | новый документ |
| `⌘⇧P` | новое приватное окно |
| `⌘L` | каретка в адресную строку |
| `⌘K` | строка ассистента |
| `⌘⇧A` | панель агента |
| `⌘Y` | история профиля |
| `⌘D` | закладка на активную страницу (ещё раз — удалить) |
| `⌘⌥B` | закладки и поиск по ним |
| `⌘S` / `⌘⇧S` | сохранить / сохранить как… |
| `⌘⇧L` | перевести страницу |
| `⌥⇧T` | перевести выделенное |
| `⌥⇧H` | выделить выбранное на странице |
| `⌥⇧P` | видео в плавающее окошко «картинка в картинке» и обратно |
| `⌘` + клик по ссылке | открыть в новом окне справа, в фоне |
| `Esc` | закрыть обзор; иначе клавиша страницы |

## Стартовая страница

| | |
|---|---|
| набор текста | подсказки: адрес, страницы из истории, подсказки поисковика |
| `↑` `↓` | по строкам |
| `↩` | открыть выбранное или введённое |
| `Esc` | очистить поле |

## Закладки `⌘⌥B`

| | |
|---|---|
| набор текста | поиск по смыслу; под каждой строкой — совпавший кусок |
| `↑` `↓` `↩` | по строкам, открыть новым окном |
| `⌘⌫` | удалить закладку вместе с файлом |
| `Esc` | закрыть |

## История `⌘Y`

| | |
|---|---|
| набор текста | фильтр по заголовку и адресу |
| `↩` | открыть новым окном |
| `⌘⌫` | забыть запись |
| `Esc` | закрыть |

## Панель агента `⌘⇧A`

| | |
|---|---|
| `↩` | отправить |
| `⌘↩` | отправить, даже когда поле многострочное |

## Обзор

| | |
|---|---|
| `↩` | подтвердить имя рабочего стола, пока его переименовывают |

::: tip Две мелочи, о которых стоит знать
`⌥W`, `⌥O` и `⌥C` перехватываются раньше всех, так что эти символы не набрать в
поле ввода.

Стрелки — нет: пока каретка стоит в адресной строке или в строке ⌘K, `⌥←` и `⌥→`
остаются переходом по словам, как и раньше. Внутри страницы они принадлежат
ленте — поле на странице не отличить от самой страницы.
:::
