# Расширения

Savoia умеет ставить браузерные расширения — из папки, `.zip`, `.crx` или `.xpi`.
**Конфигурация ▸ Расширения**

Диалог установки говорит, что будет и что не будет работать у **конкретного**
расширения, ещё до того, как оно запустится, и вердикт остаётся на строке в списке.

## Что работает

| | |
|---|---|
| фоновая страница и service worker | запускается, `browser.*` на месте |
| `storage`, `alarms`, `cookies` | работают |
| `tabs.query`, `tabs.onUpdated` | работают: расширение видит вкладки Savoia с их адресами и заголовками |
| content-скрипты из манифеста | **выполняются**, DOM доступен |
| динамически зарегистрированные скрипты | выполняются |
| `runtime.sendMessage` из content-скрипта, `tabs.sendMessage` в него | работают, в обе стороны |
| `scripting.executeScript`, `scripting.insertCSS` | работают |
| `declarativeNetRequest` | **блокирует по-настоящему** — и подзапросы, и переходы |
| всплывающее окно расширения | работает, кнопка живёт в верхней строке |
| страница настроек расширения, другие его страницы, его новая вкладка | открываются вкладками |

## Что не работает

| | |
|---|---|
| `webRequest` | в WebKit его нет вообще |

## uBlock Origin Lite

MV3-блокировщик, у которого есть сборка ровно под этот API. Он ставится и
**блокирует**: на adblock-tester.com профиль, в котором ничего не включено,
набирает 43–48 из 100, тот же профиль с uBOL — 91. Счётчик на его кнопке свой
у каждой вкладки, сайт, выключенный в нём, остаётся выключенным после
перезагрузки, а в режиме «полный» рекламные блоки исчезают со страницы.

[Собственная блокировка Savoia](/blocking) набирает на той же странице 92 и ни от
каких расширений не зависит.

## Правила

- **Расширение принадлежит профилю**: своё хранилище, свой контроллер. Разные
  профили — разные расширения.
- **В приватном окне расширения не работают вовсе.** Приватный просмотр нигде не
  записывается, а хранилище расширения — это запись.
- **Разрешения** выдаются при установке, там же, где диалог их перечислил; всё,
  что расширение попросит позже, спрашивается отдельно.
- Установка или включение расширения пересобирает открытые страницы: страница,
  открытая до его появления, иначе никогда бы его не увидела.
- Расширения из App Store подключить нельзя: они принадлежат своим приложениям.
- Подпись `.crx` никто не проверяет — как и написано в диалоге установки: из
  того, что расширение откуда-то скачано, не следует ничего.
