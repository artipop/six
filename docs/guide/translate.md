# Перевод страниц

Перевод идёт **на самой машине**, средствами системы: без ключа, без квоты и без
отправки страницы кому бы то ни было. Языковой пакет скачивается один раз, потом
работает и без сети.

| | |
|---|---|
| `⌘⇧L` | перевести страницу |
| `⌥⇧T` | перевести выделенное |
| **Вид ▸ Перевести страницу / Перевести выделенное…** | то же самое |

Кнопка перевода живёт в адресной строке — туда идут, чтобы **попросить**
перевод. Когда страница написана не на вашем языке, она предлагает себя сама.

## Пока переводится

Над страницей появляется полоска — не шесть пикселей в конце адреса, а строка
там, где страница:

| | |
|---|---|
| **Загружается `<язык>` — загрузка продолжится в фоне** | системе не хватает языкового пакета. Сколько именно осталось, система не сообщает, поэтому и полоска не врёт цифрой |
| **Перевод на `<язык>`…** | идёт, с делением на сделанное и общее |
| ошибка с причиной | и кнопка **Повторить** |

Кнопка **Стоп** прекращает перевод. Полоска исчезает, когда сказать больше
нечего: готовый перевод виден по адресной строке и сам за себя отвечает.

## Оригинал и перевод

**Показать оригинал** и **Показать перевод** переключают страницу туда-обратно:
перевод при этом никуда не девается, это переключатель, а не отмена.

**Всегда переводить `<язык>`** запоминает решение для этого языка, чтобы больше не
спрашивали.

## Чего перевод не сделает

- если системе не завезли нужный язык, VI скажет об этом и подскажет, где его
  добавить: Системные настройки › Основные › Язык и регион › Языки перевода;
- пары, которой у системы нет вообще, не будет — так и написано;
- страница, на которой ещё нечего переводить (не догрузилась), об этом сообщит;
- язык страницы иногда определить не удаётся — тогда его придётся выбрать
  самому через **Перевести на…**.
