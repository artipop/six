# Поиск на странице

`⌘F` — или **Вид ▸ Найти на странице…** — открывает полоску поиска под адресной строкой, в той вкладке, где вы
нажали. Курсор уже в поле: печатайте.

| | |
|---|---|
| поле **Найти** | страница переходит к совпадению и выделяет его уже при наборе |
| **Ничего не найдено** | появляется красным, если совпадений нет |
| `↩` или кнопка ˅ | **Следующее совпадение (⏎)** |
| `⇧↩` или кнопка ˄ | **Предыдущее совпадение (⇧⏎)** |
| `Esc` или крестик | **Закрыть (⎋)** |

После последнего совпадения поиск возвращается к первому, и наоборот.

## Что ищется

- Регистр не важен: `савоя` найдёт «Савоя».
- Ищет сам WebKit, так же, как Safari: по видимому тексту страницы, включая встроенные рамки (`iframe`).

## Для каждой вкладки свой поиск

Полоска принадлежит вкладке. Закройте её, и запрос останется: следующий `⌘F` в этой вкладке откроет полоску с тем же
текстом. В другой вкладке поиск начнётся с чистого поля.
