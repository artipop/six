# Агенты ⌘⇧A

`⌘⇧A` открывает панель агента. Агент здесь — это Claude Code или Codex,
запущенный на вашей машине и умеющий **водить браузер**: открывать окна в
нужный рабочий стол, читать страницы, пересказывать их, двигать и закрывать
окна.

Разговор идёт по ACP (Agent Client Protocol) — тому же протоколу, по которому
эти агенты разговаривают с редакторами. VI отдаёт агенту сам себя как MCP-сервер,
поэтому инструменты браузера у агента появляются сами собой.

## Что нужно поставить

Панель проверяет окружение вашей оболочки и говорит, чего не хватает:

| | |
|---|---|
| адаптер уже на `PATH` | используется напрямую |
| есть только `npm` | кнопка **Установить** ставит адаптер глобально; до тех пор он запускается через `npx` |
| нет Node.js | ссылка на страницу загрузки |
| нет самого `claude` / `codex` | панель предупредит: **Установите Claude Code и один раз запустите `claude`, чтобы войти** |

Проверяется именно интерактивная login-оболочка, так что nvm и homebrew из
`.zshrc` учитываются.

## Как это выглядит

В панели идёт расшифровка разговора: сообщения, планы, вызовы инструментов и
запросы разрешений. Вызов инструмента подписан по-человечески — `six
open_window`: сервер, пробел, метод. То, что агент назвал сам (`Read`, `Bash`,
целое предложение), остаётся как есть.

Когда агент просит разрешение, в расшифровке появляются кнопки. Пока не ответите
— он ждёт.

## Где агент работает

По умолчанию — в папке черновиков профиля (`Profiles/<имя>/Scratchpad`), и
панель так и пишет: «черновики профиля `<имя>`». **Выбрать…** назначает другую
папку; она запоминается на профиле, показывается целиком, и крестик возвращает
черновики.

Папка черновиков намеренно **не** папка закладок: вопрос про сохранённую
страницу должен идти через поиск по смыслу, а не через перебор файлов рядом.

Смена профиля меняет папку — следующий запрос переподключит агента к новой.

## Разговоры

Разговор принадлежит агенту в папке: сменили профиль или агента — сменился и
показанный разговор. Разговоры сохраняются вместе с остальной сессией, и при
следующем запуске VI просит агента продолжить прежнюю сессию. Если тот не умеет
или сессия потерялась, начинается новая, а прежняя расшифровка остаётся выше как
запись.

✎ в шапке панели забывает текущий разговор и его сессию.

**Другая модель** в панели пригодится, если модель по умолчанию у вашего
`claude` недоступна через SDK.

## Что агент умеет в браузере

Словарь у инструментов продуктовый: **окно** (страница) в **рабочем столе**
(ленте) **профиля**. По умолчанию всё относится к тому, что на экране.

| | |
|---|---|
| посмотреть | перечислить столы и окна, прочитать текст страницы, её ссылки, пересказать её |
| открыть | найти в вебе; открыть окно по адресу или по запросу — в том числе **в фоне**, чтобы экран не прыгал; открыть приватное окно |
| подвигать | перейти в окно, перенести его на другой стол, закрыть |
| разобраться | что страница вывела в консоль, какие запросы сделала, снимок страницы, выполнить код на странице |
| написать | завести документ, писать в него по разделам, сослаться на источник, выделить нужные абзацы |
| закладки | перечислить, найти по смыслу, прочитать, добавить, перечитать, удалить |

Две строки про консоль и сеть требуют **Разработка ▸ Записывать консоль и
сеть** — см. [инструменты разработчика](/devtools).

## Тот же агент на строке ⌘K

В меню моделей строки `⌘K` есть **Claude Code (ACP)** и **Codex (ACP)**. Это та
же сессия и та же расшифровка, что в панели: запросы разрешений появляются прямо
в карточке ответа, а рядом с именем модели видно, каким инструментом агент
сейчас занят.

## Браузер как MCP-сервер для чего угодно ещё

Тот же бинарник, запущенный как `six --mcp`, — это MCP-сервер поверх работающего
приложения. Любой клиент MCP может подключиться к нему и водить браузер так же,
как это делает панель. Например:

```sh
claude mcp add six -- /Applications/six.app/Contents/MacOS/six --mcp
```

::: warning Кто может подключиться
К сокету может подключиться любой процесс, запущенный от вашего пользователя;
отдельной аутентификации там нет, только права на файл. Сами агенты при этом
по-прежнему спрашивают разрешение перед вызовом инструмента.
:::
