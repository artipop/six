# Знакомство

При самом первом запуске Savoia открывает вкладку **Знакомство** и задаёт один вопрос: нужны ли языковые модели.

## Использовать языковые модели?

Модели нужны для строки `⌘E`, действий над выделенным текстом, панели агента, глубокого исследования и MCP-сервера.

| ответ | что будет |
|---|---|
| **Да, использовать** | модель на устройстве ничего не отправляет с этого Mac; для остальных нужен свой ключ. Дальше второй шаг |
| **Нет, не использовать** | ничего не загружается и не добавляется в страницы. Поиск по закладкам и перевод работают. Вкладка закрывается |

## Какая модель будет отвечать?

Четыре карточки, выбранная обведена цветом профиля:

| карточка | что это |
|---|---|
| **На устройстве** | модель Apple, ничего не покидает Mac |
| **Claude Code** | ваша подписка Claude, через claude CLI |
| **Codex** | ваша подписка ChatGPT, через codex CLI |
| **Ключ API** | Anthropic или любой OpenAI-совместимый сервер; в поле **Модель** выбирается конкретная, ниже вводятся адрес и ключ |

Под Claude Code и Codex показано, установлен ли инструмент; установить его можно тут же.
Если карточка **Ключ API** недоступна, под ней написано: «Удалённые модели недоступны: Foundation Models в SDK и в ОС не совпадают».

**Назад** возвращает к вопросу, **Готово** запоминает выбор и закрывает вкладку. Выбранная модель отвечает и на `⌘E`, и в панели агента.

Если закрыть Savoia до **Готово**, вопрос задаётся снова при следующем запуске.

Ответ можно изменить в любой момент: **Конфигурация ▸ Ассистент**, подробнее — [Конфигурация](configuration.md), [Ассистент](assistant.md) и [Агенты](agents.md).
