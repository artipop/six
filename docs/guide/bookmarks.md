# Закладки и история

Закладка в VI — это три вещи сразу: строка в списке, **читаемая копия страницы
файлом на диске** и место в индексе, по которому её можно найти по смыслу, а не
по заголовку.

| | |
|---|---|
| `⌘D` | сохранить активную страницу (ещё раз — удалить закладку) |
| звёздочка справа от адресной строки | то же самое; закрашена, когда страница сохранена |
| `⌘⌥B` | список закладок и поиск по ним |

## Что сохраняется

Не адрес, а сама страница. VI вытаскивает из неё основное содержимое —
заголовки, абзацы, списки, цитаты, код, ссылки, таблицы, крупные картинки — и
кладёт рядом Markdown-файл в `Profiles/<имя>/Bookmarks/`. Навигация, боковики,
подвалы, формы, баннеры о куках и всё, что называет себя комментариями или
рассылкой, выбрасывается.

Поэтому сохранённое читается и через год, и без сайта. Файл начинается с
заголовка, адреса, сайта, языка, профиля и даты — по нему можно восстановить
строку, если база потеряется. Удалить закладку — удалить и файл.

## Поиск по смыслу

`⌘⌥B` ищет не по буквам заголовка, а по тому, о чём страница была. Под каждой
найденной строкой показан тот кусок текста, который совпал.

Это работает **между языками**: русский вопрос находит английскую страницу, и
наоборот. Модель для этого (~470 МБ) скачивается один раз при первом
использовании и дальше не выходит с машины никогда; пока она идёт, это видно в
подвале окна закладок. Поиск по заголовку работает с первой секунды, не
дожидаясь ничего.

::: tip Что честно сказать про качество
Внутри одного языка ранжирование верное. Между языками оно верное для тем и
шаткое для деталей: английский вопрос про цифру в русском абзаце может
проиграть неродственной английской странице.
:::

`↑` `↓` ходят по строкам, `↩` открывает выбранную новым окном, `⌫` удаляет
закладку вместе с файлом, `Esc` закрывает. В контекстном меню — **Показать файл
в Finder**.

## И не спрашивая

Тот же поиск работает там, где вы обычно ничего не ищете, — под полем
[стартовой страницы](/start#личныи-поиск). Пока вы набираете запрос, над
подсказками поисковика встают до двух ваших сохранённых страниц, если они про
это. Отдельно включать нечего: закладки есть — строки появляются, закладок нет —
не появляется ничего, и модель ради этого не скачивается.

В приватном окне их нет.

## Страницы меняются

Закладки перечитываются по расписанию: **Закладки ▸ Перечитывать сохранённые
страницы** — никогда / ежедневно / **еженедельно** (по умолчанию) / ежемесячно.
Перечитывание идёт в фоне, по одной странице, с куками профиля — так страница за
логином читается такой, какой её видите вы.

Если текст не изменился, отмечается только дата. Если изменился — файл и индекс
переписываются. Если страница не открылась, старая копия остаётся, а в списке
появляется оранжевая стрелка с причиной.

**Обновить закладку** и **Обновить закладки — `<профиль>`** делают то же по
требованию.

## Что видят ассистент и агенты

**Закладки ▸ Ассистент ищет: Этот профиль / Все профили** — одна настройка на
всё: она решает, в чьих закладках ищут [ассистент ⌘K](/assistant) и
[агенты](/agents), когда не сказано иначе. Они умеют перечислять закладки,
искать по смыслу, читать сохранённый файл целиком, добавлять, перечитывать и
удалять.

Рабочая папка агента намеренно **не** папка закладок: вопрос про сохранённое
должен идти через поиск по смыслу, а не через `grep` по рабочей папке.
