# Keyboard shortcuts

On a page, `Enter` submits a form or activates a button, while `Space` and `Shift+Space`
scroll down and up. In a text field they remain typing keys. When the page has nothing
to do with the key and nothing to scroll, there is no system alert sound — the same holds
for `Esc`, the arrows, `Home` and `End`.

## Tabs

| | |
|---|---|
| `⌘T` | new tab — at the very end, outside every group |
| `⌘W` | close the tab |
| `⌘⇧T` | put the last closed tab back where it stood |
| `⌘⇧]` `⌘⇧[` | next / previous tab |
| `⌘1` … `⌘8` | that tab, `⌘9` the last one |
| `⌘`-click `⇧`-click on a tab | pick tabs one by one / a run of them; the menu of any of them is about all of them |

## Flying between tabs

| | |
|---|---|
| `⌃Tab` | hold `⌃`: every tab of the profile, from every group, as pictures, in the order you looked at them, the one you would land on in the middle. Each press is a step along the ring; letting `⌃` go flies there |
| `⌃⇧Tab` | the same ring over the group you are in; once the ring is open, a step back |
| `⌃⇧←` `⌃⇧→` | the card to the left or right. The `⇧` is not decoration: macOS keeps bare `⌃←` / `⌃→` for itself (Mission Control, move to a space), and they never reach the browser |
| `↩` | fly now, without waiting for `⌃` to come up |
| `Esc` | let go of the ring without going anywhere |

A single `⌃Tab` is a toggle between the last two tabs. Other profiles are never in the
ring, and it remembers this run only.

## Browser

| | |
|---|---|
| `⌘R` | reload the page (the ⟳ beside the address does the same) |
| `⌘⇧R` | reload from the server — past the cache, everything asked for again |
| `⌘.` | stop loading |
| `⌘[` `⌘]` | back / forward through the tab's own history (the ‹ › do the same) |
| `⌘,` | settings — `savoia://configuration`, in a tab like any other address |
| `⌘⇧N` | new document |
| `⌘⇧P` | new private window |
| `⌘⇧C` | copy the tab's whole address; a tick appears in the field (Edit ▸ Copy Address does the same). A start page, a document or an app has nothing to copy, and there the key does nothing |
| `⌘F` | find on the page; `↩` / `⇧↩` for the next / previous match, `Esc` to close |
| `⌘L` | caret into the address field |
| `⌘E` | the assistant line: show or put away |
| `⌘⇧E` | chats with agents, in a tab |
| `⌘Y` | the profile's history |
| `⌘D` | bookmark the page (again: remove it) |
| `⌘⌥B` | bookmarks and searching them |
| `⌘S` / `⌘⇧S` | save / save as… |
| `⌘⇧L` | translate the page |
| `⌥⇧T` | translate the selection |
| `⌥⇧H` | highlight the selection on the page |
| `⌥⇧P` | the video into the floating picture-in-picture window and back |
| `⌥⌘A` | the [accessibility overlay](/en/accessibility) over the page, on and off |
| `⌥⌘I` | the [web inspector](/en/devtools) on this tab, open and close |
| `⌘` + click a link | open it in a new tab, in the background |

`⌥⇧T`, `⌥⇧H` and `⌥⇧P` go to the page first: if a site uses the combination itself,
it stays the site's. In a text field they type their characters.

## The start page

| | |
|---|---|
| typing | completions: an address, pages from history, the engine's suggestions |
| `↑` `↓` | walk the rows |
| `↩` | open the selected row, or what you typed |
| `Esc` | clear the field; on an empty field, let go of the caret. A click beside the field does the same |

## Bookmarks (`⌘⌥B`)

| | |
|---|---|
| typing | search by meaning; the matching passage under each row |
| `↑` `↓` `↩` | walk the rows, open in a new tab |
| `⌘⌫` | remove the bookmark and its file |
| `Esc` | close |

## History (`⌘Y`)

| | |
|---|---|
| typing | filter by title and address |
| `↩` | open in a new tab |
| `⌘⌫` | forget the visit |
| `Esc` | close |

## The ⌘E line

| | |
|---|---|
| `↩` | ask; on an empty line, apply the answer already there |
| `←` `→` | at a field or a selection, choose an action |
| `/` | the actions as a list; with an agent, your earlier conversations too |
| `↑` `↓` | after `/`, walk the conversations found |
| `⇥` | after `/`, put the action found into the line as a chip |
| `⌘⌫` | on an empty line, take the action's or the conversation's chip off |
| `Esc` | put the line away |

## A chat tab

| | |
|---|---|
| `↩` | send |
| `⌘↩` | send, even while the field is multi-line |
