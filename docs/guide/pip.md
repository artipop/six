# Картинка в картинке

Видео уходит со страницы в маленькое окно поверх всех приложений и продолжает играть. Страница остаётся обычной
вкладкой.

| | |
|---|---|
| `⌥⇧P` | видео вкладки в плавающее окно и обратно |
| **Вид ▸ Картинка в картинке** | то же самое |
| **Картинка в картинке** в [контекстном меню страницы](windows.md#контекстное-меню-страницы) | то же самое |
| кнопка в элементах управления видео | то же самое |

Пока окошко на экране, можно переключать вкладки, сворачивать группу, менять профиль: плеер остаётся где стоял и
играет. Вкладка с таким видео не выгружается из памяти, даже если открыто много других.

## Чего ждать

- Пункт меню не серый ни на каких страницах: есть ли на странице видео, знает только сама страница. Там, где видео нет,
  ничего не произойдёт.
- Если сайт занял `⌥⇧P` для себя, сочетание остаётся сайту; в текстовом поле оно печатает свой символ
  ([клавиши](hotkeys.md)).
- Положение и размер окошка запоминает система, одни для всех приложений. Привязать его к окну Savoia нельзя: плеер
  рисует сама система.
