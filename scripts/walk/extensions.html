Extensions, and uBlock Origin Lite

Messaging, scripting and uBOL's blocking were measured through the extension's own messages. Its popup, the badge on its button and Savoia's own controls for an extension were never pressed. Needs uBlock Origin Lite installed; skip the station otherwise.

Three blocks an ad blocker's cosmetic rules usually hide. In uBOL's complete mode they should vanish; in optimal or with no filtering they stay.

The popup and its slider


  1. Click uBOL's button in the toolbar.
  2. Move the filtering slider to complete, reload, press "Count the visible blocks". Then to optimal, reload, count again.


the popup hangs from its button and the slider moves; complete hides the blocks (0 of 3, or fewer than 3), optimal shows them. These blocks are ours, not from a filter list — if complete hides none, say so and judge on a real site instead.



A tab opened after the mode changed


  1. Set complete, reload here. Set optimal. Now open this page in a new tab and count there; then reload this tab and count here.


both tabs agree. A new tab that still hid the block while the old one showed it was seen once and not explained.



The number on the button


  1. Open a news site with ads. Look at uBOL's button, then switch to another tab and back.


a count on the button that belongs to the tab in front and changes when you switch tabs.



Off for one site


  1. In the popup, switch filtering off for this site. Reload. Close and reopen the tab.


the site stays unfiltered after the reload and in the new tab; other sites are filtered as before.



Savoia's own controls for an extension


  1. Configuration ▸ Extensions: press Open Options Page for uBOL.
  2. For an extension that offers a new-tab page, switch on the toggle that lets it stand in for the start page, open a new tab, and switch it off again.


the options page opens as a tab; with the toggle on, a new tab shows the extension's page, and Savoia's start page is back when it is off. Skip the second if no extension offers one.



What the install dialog says


  1. Install any extension from a folder or an archive and read the list in the dialog before agreeing.


scripting and content scripts are listed as working — not "unchecked", which was true until 8 October.
