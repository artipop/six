The context menu and a ⌘-click

The page's menu is an NSMenu built by Savoia since the move to WKWebView. Nobody has opened it in Savoia.

On a link

  1. Right-click this link.
  2. Try each item once: open in a new tab, open behind, copy the link.

items for a link, in your interface language; "behind" opens a tab without leaving this one; the copied address pastes.

On the page, on a selection, on a picture

  1. Right-click empty space.
  2. Select this sentence and right-click the selection.
  3. Right-click the picture.

three different menus: the page's (back, reload, Save As, Inspect Element when Develop is on), the selection's (copy, look up, the assistant's verbs if any), the picture's.

Share, and an extension's items

  1. In the page's menu find Share and open it.
  2. If an extension that adds menu items is installed, look for them.

the system's share list; an extension's items under its name. Skip the second if you have no such extension.

⌘-click, and a plain click on target=_blank

  1. ⌘-click this link.
  2. Plain-click this one, which asks for a new window.

the first opens a tab behind and you stay here; the second opens a tab and takes you there.

Inspect Element

  1. With Configuration ▸ Develop on, right-click the heading of this page and choose Inspect Element.
  2. Close the inspector with ⌥⌘I.

the inspector opens on that element and closes; the page keeps its size afterwards.
