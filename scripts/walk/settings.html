Switches nobody has pressed

Each of these was set through the database or a tool and read back, never clicked. No widgets here — the work is in Configuration and the menus.

The blocker's page half

  1. Configuration ▸ Privacy ▸ Blocking: find the switch for scriptlets and extended CSS. It should be off.
  2. Switch it on, reload a site with stubborn ads, switch it off again.

off by default; on, the page changes (fewer leftovers of blocked ads); the label reads sensibly in your language and does not describe Savoia in the third person.

Allow Remote Automation

  1. Configuration ▸ Develop: press the switch on, then off.
  2. With it on, hover over the orange mark of an automation tab if you have one.

off by default; the switch stays where you put it after a relaunch. Skip the mark if no automation tab is open.

The Web Inspector

  1. ⌥⌘I on this tab. Dock it, undock it, close it.
  2. Open it, then leave this tab alone until it is put to sleep (or relaunch), and come back.

it opens on this page; the page keeps its size after closing; a tab that slept does not come back broken.

Find on the page

  1. ⌘F, type "nobody" one letter at a time, Return twice, ⇧Return, Esc.
  2. Type something that is not here.

the match is selected and scrolled to as you type, Return walks forward and wraps, and "No Results" shows in red for the second.

⌘E on a selection and in a field

  1. Select this sentence and press ⌘E.
  2. Click into the field below, type a few words, select two of them, press ⌘E.

the line appears at the selection each time and is about what you selected.

The key self-test, on a Mac with nothing in front

  1. Quit the dev Savoia. In a terminal: SAVOIA_KEY_SELFTEST=1 <path to Debug Savoia>/Contents/MacOS/Savoia, and do not touch the Mac until it stops printing.

no line reads "no key window"; paste the last lines to the session if any does.

Translation

  1. Open a long page in a language you do not read and accept the offer to translate, or use the menu.
  2. Scroll up and down while it works.

text is replaced outward from what is on screen, in both directions, and the original comes back when you ask.
