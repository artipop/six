# site

Страница Savoia: как работает, факты, ссылка на руководство. Статика — HTML,
`styles.css`, `app.js` и шрифты; сборка нужна, чтобы сложить их в `dist/` с хешами
в именах. Цены, предзаказа и реквизитов здесь нет: продукт в разработке.

```
npm ci
npm run dev        # http://localhost:5173 — страница и руководство вместе
npm run dev:site   # только страница, без руководства
npm run build      # dist/ — только страница
npm run build:all  # dist/ вместе с руководством в dist/docs
npm run preview    # посмотреть собранное
```

Страница собирается **сама по себе**: `dist/` — готовый сайт. Вместе с другими
продуктами её собирает `../../deffun`: запускает `npm run build` здесь и копирует
`dist/`. Где страница будет лежать, говорит переменная **`BASE`** (по умолчанию `/`,
в общей сборке `/savoia/`); руководство всегда лежит в `BASE` + `docs/`, поэтому ссылки,
которые Vite сам не переписывает, пишутся как `%BASE_URL%docs/`. Куда ведёт логотип
«deffun», говорит `VITE_HOME_URL`: в одиночку это сама страница (`.env`), в общей
сборке — главная.

В деве руководство (`../docs/guide`) — отдельный сервер на 5176, а этот проксирует
на него `/docs` (с `ws` — для горячей перезагрузки). `npm run dev` поднимает оба.

## Дизайн

Страница и руководство выглядят как само приложение. Источники — иконка
(красное крыло в голубом небе, `icon-*.png` сделаны из `Savoia/Assets.xcassets/IconSky`),
фоны стартовой страницы (синий в оранжевый), капсулы и скругления в 14 pt, системный шрифт.
Светлая тема — дневное небо, тёмная — вечернее; акцент — цвет крыла.

- **Токены** — в начале `styles.css` (`--canvas-rgb`, `--surface-rgb`, `--ink-rgb`,
  `--accent-rgb` для текста и линий, `--button-rgb` для заливки кнопок, `--sky-rgb`, `--glow-rgb`,
  радиусы) и в `../docs/guide/.vitepress/theme/custom.css` (переменные `--vp-*`). Значения
  меняются в обоих местах.
- **Шрифты** — стек `-apple-system, SF Pro, Inter Variable, system-ui`: на устройствах Apple это
  системный шрифт приложения, на остальных — Inter (SIL OFL, лицензия лежит рядом) из `fonts/` и
  `../docs/guide/.vitepress/theme/fonts/`. Моноширинный — системный `ui-monospace`.
- **Контраст** — белый текст на кнопке `#d91e18` даёт 5:1, акцент для текста `#c8141a` на
  светлом фоне — 5,3:1, `#ff6052` на тёмном — выше 6:1.

## Профили

Страница собирается для разных площадок: `PROFILE=org` (по умолчанию) или
`PROFILE=personal`, это режим Vite. Значения лежат в `.env.<профиль>` (название
в шапке и футере, домен для canonical), а блоки, которые различаются
(`<!--profile:имя-->` в `index.html`), — в `profiles/<профиль>/<имя>.html`;
без файла блок пустой. Значения `personal` пока пустые, там стоят `TODO`.
Руководство берёт имя в `© 2026` из `PROFILE_NAME`. Общая сборка —
`../../deffun`.
